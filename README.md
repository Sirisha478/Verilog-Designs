# APB Master-Slave Design

## Project Description
This project implements an AMBA APB (Advanced Peripheral Bus) Master and Slave using Verilog HDL.

## Files

- `apb_master.v` - APB Master design
- `apb_slave.v` - APB Slave design
- `top.v` - Top-level module connecting Master and Slave
- `tb.v` - Testbench for verification

## Features

- APB Master implementation
- APB Slave implementation
- Read and Write transactions
- APB protocol-based communication
- Verilog testbench for verification

## Tools Used

- Verilog HDL
- Digital Design
- APB Protocol
- Simulation and Verification
- Questasim Tool
